A one-line weather forecast for a city that does not exist, read the way a
deadpan TV meteorologist would read it off the map. The forecast is absurd
and still believable: a concrete number, a concrete image, and a twist at
the end — rain that falls upward, on schedule, until 6 p.m.

## The entry

> In Gloombury, rain falls upward at 14 miles an hour until 6 p.m., when it remembers gravity. Carry an umbrella — and stand on it.

## How it works

`main.ts` (Node 22, standard library only, deterministic) writes that single
line to `$MAKEFUN_OUTPUT_DIR/entry.txt`. No network, no secrets, no input
data — the forecast is fixed, so every run produces the same file.

```sh
node main.ts
```
